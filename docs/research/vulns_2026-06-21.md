> **UNCERTAINTY**: All CVE IDs below should be cross-verified at nvd.nist.gov before minting any finding. Agent-returned IDs may be partially hallucinated. CISA KEV entries are the most reliable source. Version ranges are as reported — confirm against vendor advisories.

### TOP PRIORITY — Unauth, high-severity, in our tech stack

**1. CVE-2026-8206 — Kirki Freeform Page Builder (WordPress) — Unauth Admin Takeover (CVSS 9.8)**
- Versions: 6.0.0–6.0.6
- Mechanism: Password reset doesn't validate email matches the account — supply admin username + attacker email → get reset link → full takeover.
- **Detect (unauth, safe):** `curl -s https://<host>/wp-content/plugins/kirki/readme.txt | grep 'Stable tag'` → version in 6.0.0–6.0.6 = LEAD.
- In-range verifiable unauth: Yes (version check only — do NOT trigger the reset).
- Sources: [threat-modeling.com](https://threat-modeling.com/kirki-wordpress-plugin-account-takeover-cve-2026-8206/) | [orca.security](https://orca.security/resources/blog/kirki-wordpress-plugin-vulnerability-cve-2026-8206/)

**2. CVE-2026-8181 — Burst Statistics WP Plugin — Unauth Admin Account Creation (CVSS 9.8)**
- Versions: 3.4.0–3.4.1.1
- Mechanism: `is_mainwp_authenticated()` returns null-on-failure; PHP treats null as truthy → REST API auth bypass → create new admin user with any creds.
- **Detect (unauth, safe):** `/wp-content/plugins/burst-statistics/readme.txt` version probe. Also: `GET /wp-json/wp/v2/users` — if returns user list, baseline WP enumeration works.
- In-range verifiable unauth: Yes.
- Source: [cybersecuritynews.com](https://cybersecuritynews.com/wordpress-plugin-vulnerability-exposes-websites/)

**3. CVE-2026-4020 — Gravity SMTP (WordPress) — Unauth API Key / OAuth Token Leak (ACTIVELY EXPLOITED)**
- 17M+ attack attempts as of June 21; 4M+ in a single day (June 7). Affects ~100K sites.
- Mechanism: Single unauthenticated GET/POST drains SMTP integration API keys and OAuth tokens.
- **Detect (unauth, safe):** `/wp-content/plugins/gravitysmtp/readme.txt` version check. Sites running Gravity Forms suite are high-probability candidates.
- In-range verifiable unauth: Yes (version/presence check only).
- Source: [techtimes.com](https://www.techtimes.com/articles/318768/20260621/wordpress-email-plugin-flaw-triggers-17-million-attacks-gravity-smtp-leaks-live-api-keys.htm)
- ⚠️ Version range NOT confirmed from NVD — verify before scoring.

**4. CVE-2026-42945 — "NGINX Rift" — Heap Buffer Overflow in rewrite module (CVSS 9.2)**
- Versions: NGINX Open Source 0.6.27–1.30.0 (fixed 1.31.0+); NGINX Plus R32–R36 (fixed R37+).
- Mechanism: PCRE capture size mismatch in ngx_http_rewrite_module → worker crash (reliable DoS) / RCE when ASLR bypassed.
- **Detect (unauth, safe):** `curl -sI <host> | grep -i server` → `nginx/1.X.Y` where Y ≤ 30 = LEAD. Our current dataset already shows `Nginx:1.29.7` as top tech — **that version is in-range**.
- In-range verifiable unauth: Yes (version check). DoS confirmation is destructive — version-only LEAD in our pipeline.
- Sources: [AlmaLinux](https://almalinux.org/blog/2026-05-13-nginx-rift-cve-2026-42945/) | [F5 advisory K000161019](https://my.f5.com/manage/s/article/K000161019)

**5. CVE-2026-6722 — PHP SOAP Extension UAF → RCE (CVSS 9.5)**
- Versions: PHP 8.2.x < 8.2.31, 8.3.x < 8.3.31, 8.4.x < 8.4.21, 8.5.x < 8.5.6
- Mechanism: Duplicate keys in `apache:Map` SOAP node → double-free → arbitrary write → RCE.
- **Detect (unauth, safe):** SOAP endpoint probe: `GET /?wsdl` returning WSDL XML, or `Content-Type: application/soap+xml` in responses, or paths `/soap`, `/api/soap`. `X-Powered-By: PHP/8.X.Y` header gives version.
- In-range verifiable unauth: Yes if SOAP endpoint reachable unauth. Do not send malicious payload — version + SOAP exposure = LEAD.
- Source: [securityonline.info](https://securityonline.info/php-security-patch-rce-soap-cve-2026-6722/)

**6. CVE-2026-23918 — Apache HTTP Server 2.4.66 Only — HTTP/2 Double-Free / RCE (CVSS 8.8)**
- Versions: Apache 2.4.66 **only** (fixed in 2.4.67). Very tight window = high signal if matched.
- **Detect (unauth, safe):** `curl -sI --http2 <host> | grep -i server` → `Apache/2.4.66` = LEAD.
- In-range verifiable unauth: Yes.
- Sources: [thehackernews.com](https://thehackernews.com/2026/05/critical-apache-http2-flaw-cve-2026.html) | [security.berkeley.edu](https://security.berkeley.edu/news/critical-apache-2466-http2-flaw-allows-rce-dos-cve-2026-23918)

### MEDIUM PRIORITY — Narrower scope or partial-auth required

**7. Avada Builder (WordPress) < 3.15.4 — Unauth Arbitrary File Deletion**
- Fixed 2026-06-02 in 3.15.4.
- **Detect:** `curl -s https://<host>/wp-content/themes/avada/style.css | grep Version` — < 3.15.4 = LEAD. Also `X-Powered-By: Avada` or `/wp-content/themes/avada/` path existence.
- Endpoint: `wp_ajax_nopriv_fusion_form_submit_ajax` — nopriv = unauth. Do NOT send the deletion payload.
- Sources: [cybersecuritynews.com](https://cybersecuritynews.com/avada-wordpress-plugin-vulnerability/) | [gbhackers.com](https://gbhackers.com/critical-wordpress-plugin-bug/amp/)

**8. CVE-2026-46633 — Twig < 3.26.0 — PHP Code Injection via `{% use %}` Template Name (Sandbox Bypass → RCE)**
- Affects Symfony, Drupal, Sylius, Craft CMS — any PHP app where user input reaches `{% use %}` template name.
- **Detect (unauth if exposed):** `composer.lock` or `/vendor/twig/twig/CHANGELOG` accessible publicly → check `"twig/twig": "3.X.Y"` where Y < 26.
- In-range verifiable unauth: Only if templates user-controllable without auth. Otherwise requires auth context.
- Source: [symfony.com advisory](https://symfony.com/blog/cve-2026-46633-php-code-injection-via-use-template-name)

**9. CVE-2026-32271 — Craft Commerce 4.0–4.10.2 / 5.0–5.5.4 — SQLi → RCE Chain**
- Fixed in 4.10.3 / 5.5.5.
- 4-stage: SQLi in TotalRevenue widget → multi-statement PDO → unserialize gadget chain → file write → RCE. Widget creation needs CP access, BUT queue trigger is unauth: `GET /actions/queue/run`.
- **Detect (unauth):** Craft CMS fingerprint: `/index.php?p=admin`, `X-Powered-By: Craft CMS`, or `/cpresources/` paths. `GET /actions/queue/run` → 200 confirms Craft + queue exposed.
- Treat as partial-auth LEAD — unauth queue trigger alone doesn't execute the chain without prior widget creation.
- Sources: [advisories.gitlab.com](https://advisories.gitlab.com/composer/craftcms/commerce/CVE-2026-32271/) | [GitHub GHSA-875v-7m49-8x88](https://github.com/craftcms/commerce/security/advisories/GHSA-875v-7m49-8x88)

**10. CVE-2026-10520 — Ivanti Sentry — KEV — Unauth OS Command Injection → Root RCE**
- Added to CISA KEV June 11.
- **Detect (unauth):** Ivanti Sentry login page at `/mics/login` or `X-Sentry` response headers. Product banner in page title.
- Not in our top tech list but worth one ES query against Ivanti hits.
- Source: CISA KEV catalog

### HTTP/2 Bomb — Note but LOW bounty value

- **Detect:** `curl --http2 -sI <host>` confirms HTTP/2; Server header version check. Our `Nginx:1.29.7` is in-range.
- Include in n-day scan data but do not prioritize for reporting — DoS-only class has low bounty conversion.
- Source: [thehackernews.com](https://thehackernews.com/2026/06/new-http2-bomb-vulnerability-allows.html)
