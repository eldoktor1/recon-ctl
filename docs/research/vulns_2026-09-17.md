## 1. NEW — CVE-2026-75650 "StyleSmuggler", Adobe Commerce / Magento — unauth RCE, CVSS **10.0**, actively exploited, in CISA KEV ★★★
- **What:** Unauthenticated template-engine injection in Magento's style/template rendering + failed-payment email pathway → arbitrary PHP execution. No auth, no interaction. Active exploitation (Rust backdoor + PHP web shell implants) began **2026-09-04**, before the patch existed.
- **Affected:** Adobe Commerce **2.4.4–2.4.9**, Adobe Commerce B2B **1.3.3–1.5.3**, Magento Open Source **2.4.6–2.4.9** (all platforms, through Aug 2026 builds). Fixed via hotfix **VULN-39341** (APSB26-146, released 2026-09-07). Added to CISA KEV 2026-09-08.
- **Why relevant:** e-commerce/Magento sites are common on bug-bounty scope even though Magento isn't on our top-tech list — a 10.0 unauth-RCE with a 3-day active-exploitation head start before patch is exactly the "be first to fresh surface" case, and a huge severity ceiling if we catch an unpatched instance.
- **Detect (unauth, safe, in-range-verifiable):** vendor/researcher writeups deliberately withhold exploit/recon details (no public IoC/fingerprint package from Adobe/CISA/NVD). Use standard passive Magento fingerprinting instead — `Mage-Cache-Sessid`/`Mage-Messages` cookies, `X-Magento-*` response headers, `<meta name="generator" content="Magento...">`, `/media/catalog/product` paths — then pull the build/version via Composer `composer.lock`/`RELEASE_NOTES.md` if exposed, or the admin login page's asset version query-strings. No safe unauth version-disclosure endpoint is documented; treat any Magento/Adobe Commerce host without a confirmed build ≥ patched as a **version-range LEAD only** (same clamp as every other KEV tech-class match) — do NOT attempt the injection (destructive/RCE, exploitation not detection).
- **Sources:** [Tenable FAQ](https://www.tenable.com/blog/stylesmuggler-cve-2026-75650-frequently-asked-questions-about-adobe-commerce-and-magento-zero), [The Hacker News (backdoor)](https://thehackernews.com/2026/09/unpatched-magento-and-adobe-commerce.html), [The Hacker News (patch)](https://thehackernews.com/2026/09/adobe-patches-magento-zero-day.html), [Rescana KEV brief](https://www.rescana.com/post/magento-stylesmuggler-cve-2026-75650-kev)
