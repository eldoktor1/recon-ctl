### ADOPT

**nomore403** — [github.com/devploit/nomore403](https://github.com/devploit/nomore403) (1.8k⭐, last release Apr 2026)
Probes 401/403-gated routes for bypasses via path normalization, header injection (`X-Original-URL`, `X-Rewrite-URL`), method overrides, HTTP version mutations, and double-encoding — all unauthenticated, no body writes.

- **Gap it fills:** we have NO 403-bypass lane. When `recon_kr.sh` or jsintel surfaces a gated route we mark it LEAD and hand to operator. nomore403 turns that into an autonomous unauth gate: if it lands a 200, that's a reportable access-control gap with no account needed.
- **Doctrine fit:** unauthenticated, read-only, non-destructive. Rate-limit it like any prober (`--delay`). CONFIRMED bypass = genuine BAC/unauth access.
- **Integration point:** pipe `recon_kr.sh` 401/403 hits + jsintel 403-endpoint candidates through nomore403 before handing to briefing.

### EVALUATE

**URLFinder** — [github.com/projectdiscovery/urlfinder](https://github.com/projectdiscovery/urlfinder) (880⭐, v0.0.3 Mar 2025)
PD-native passive URL harvester (Wayback, OTX, URLScan, CommonCrawl) — the maintained successor to `gau`'s passive mode, with built-in scope filtering and JSONL output.

- **vs. gau:** same source set, better maintenance (gau is stale), cleaner PD ecosystem fit. Drop-in swap in `recon_params.sh` passive-URL step.
- **Action:** test side-by-side on 50 hosts; if delta of unique URLs vs gau is >0 and yield is comparable, replace gau.

---

**Gitleaks** — [github.com/gitleaks/gitleaks](https://github.com/gitleaks/gitleaks) (18k⭐, actively maintained 2026)
Fast offline regex+entropy secret scanner for git repos; no network calls; SARIF output; broader pattern coverage than trufflehog for JWTs, generic private keys, and some token types trufflehog doesn't verify.

- **vs. trufflehog `--only-verified`:** gitleaks finds candidates fast (offline, milliseconds); trufflehog verifies live (burns API rate limits on every hit). Run gitleaks first → feed candidates to trufflehog `--only-verified` for confirmation. Reduces wasted verification calls, speeds the lane.
- **Action:** add as pre-filter in `recon_ghleaks.sh` before the trufflehog verification pass.

---

**Subdominator** — [github.com/RevoltSecurities/Subdominator](https://github.com/RevoltSecurities/Subdominator) (781⭐, v3.0.2 Jun 2026)
Passive subdomain enum from 73 OSINT sources (subfinder covers ~50); SQLite-backed dedup cache; recursive mode. Extra sources include threat intel feeds and DNS datasets not in subfinder.

- **Doctrine fit:** passive-only, zero target traffic.
- **Action:** run alongside subfinder on 5 in-scope roots for 30 days; measure net-new resolved hosts. If delta >1-2% unique, add to gungnir/CT daemon. If near-total overlap, skip — not worth the API quota.

---

**InQL v6** — [github.com/doyensec/inql](https://github.com/doyensec/inql) (Burp extension, Doyensec, actively maintained 2026)
Burp extension that auto-generates all queries/mutations from a harvested GraphQL schema, organizes them for iteration, and replays with one click.

- **Not a pipeline tool** — operator-side only. When `recon-graphql` produces a `graphql_candidates_<date>.md` briefing, InQL lets the operator iterate the schema in Burp far faster than raw curl. Cut: no autonomous pipeline value; human-test accelerator only.
- **Action:** install in operator Burp. Load the introspection JSON from `recon_graphql.sh` output directly.

## False-positive patterns
- 302 redirect to login page ≠ 200 bypass; check the actual response body.
- `index.html` SPA shell returned for all routes ≠ real unauth access; verify content-type + body content.
- Some CDNs return 200 for path mutations with a downstream 403 error body — check response body.

## Severity
- Unauth access to admin/PII/internal routes: P1–P2
- Unauth access to otherwise-authed data (not admin): P2–P3
- Unauth access to non-sensitive data: likely N/A — verify content sensitivity before reporting.

## Hard lines
- Route must be in-scope + paying.
- Do NOT enumerate other users' data even if the bypass lands.
- Confirm-then-stop: one successful bypass probe is the PoC; no further traversal.
