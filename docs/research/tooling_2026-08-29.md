## 1. EVALUATE — `praetorian-inc/titus` (secrets scanner, successor lineage to Nosey Parker)
- **What it is:** Go secrets scanner from Praetorian (blog announcement Feb 26 2026, latest release v1.2.6 Jun 24 2026, 607-678★, actively released). Ships **487 detection rules** — merges Nosey Parker's original ~200 regex rules with 250+ pulled from MongoDB's Kingfisher fork — and **validates** each hit against the provider's live API (tagged `confirmed`/`denied`/`unknown`), same "verified-only" posture as our TruffleHog usage. Four interfaces: CLI, Go library, **Burp Suite extension**, **Chrome extension**. Handles JS scanning + recursive archive extraction natively.
- **Context — why it exists now:** Praetorian **archived Nosey Parker on 2026-04-24** (its Rust scanner, previously the fastest-in-class regex+Hyperscan engine); Titus is the Go reimplementation that carries its rules forward plus validation. We never adopted Nosey Parker, so this isn't a replacement for us — but it explains where Praetorian's secret-scanning effort moved, and Titus is the actively-maintained one now.
- **Why it's worth a look, not a swap:** TruffleHog (already our github-leaks + JS-intel backbone, `--only-verified`) stays superior on raw detector-type breadth (~800 credential types). Titus's actual differentiator for us is the **Burp Suite extension** — passive live secret detection inside an *authenticated* Burp-driven testing session (our `feedback_work_from_burp` / Burp MCP flow). TruffleHog only scans git history / static JS; it never sees secrets leaking in live authed API *responses* during a session. That's a genuine coverage gap Titus's Burp extension could close, unauth-safe by construction (passive detection on traffic we're already generating, not new outbound probes).
- **Doctrine fit:** unauth-safe/non-destructive ✅ (passive scan of responses we already fetch); dup-resistant ✅ (secrets-in-authed-responses is not something crowd scanners running unauth recon ever see); validation-gated ✅ (matches `engine/impact.py`'s "redact + prove recovery" posture — Titus's confirmed/denied tagging is the same idea).
- **Verdict: EVALUATE** — install the Burp extension for the NEXT authed Burp-driven session (per `reference_burp_mcp_and_automation`) and let it run passively; compare hit quality against manual review. Do NOT replace TruffleHog in `recon_ghleaks.sh`/jsintel — those stay as-is; this is a supplemental lane (secrets-in-authed-traffic), not a substitute.
- Sources: [Titus GitHub](https://github.com/praetorian-inc/titus), [Titus announcement blog](https://www.praetorian.com/blog/titus-open-source-secret-scanner/), [Nosey Parker repo (archived)](https://github.com/praetorian-inc/noseyparker)
