# Research digest — tooling — 2026-09-01 (pass 3)

## 1. EVALUATE — `betterleaks/betterleaks` (secrets scanner)
- **What it is:** New (Feb 2026) secrets scanner from Zach Rice — the original **Gitleaks author**, who forked away after losing control of the Gitleaks name/repo. Go, MIT, 1.8k★, actively maintained by a reputable single-but-known author. Detection uses **BPE-tokenization** instead of entropy/regex (claims 98.6% recall vs 70.4% for entropy-based, though that's the author's own benchmark — treat as unverified). Drop-in Gitleaks-compatible CLI/config.
- **Why it's relevant to us specifically:** it has a **live-validation feature directly comparable to our `trufflehog --only-verified` gate** — "Secrets Validation" fires an async HTTP request (defined via CEL/Expr in the rule itself) to confirm a credential is actually live before it counts as a hit. It also scans arbitrary sources beyond git history: `betterleaks dir <path>` (local FS — fits mining JS-intel/sourcemapper output) and `betterleaks stdin` (pipeable — fits our `recon_jsintel.sh`/`recon_ghleaks.sh` shape without rearchitecting).
- **Does it beat trufflehog?** Not clearly — trufflehog already does verified-live-credential detection across 800+ detector types and is what our `class-clientside-secrets`/`recon_ghleaks.sh` lanes are built around. Betterleaks' edge is claimed *recall* (fewer missed non-standard/custom-format secrets) and CEL-defined custom validators, which could catch things trufflehog's fixed detector list misses — genuinely complementary, not a strict replacement.
- **Doctrine fit:** unauth-safe ✅ (only calls out to verify secrets it already found, same posture as trufflehog verification), dup-resistant — this is capability-parity tooling (detection accuracy), not a new attack surface.
- **Verdict: EVALUATE** — run it as a **second pass** alongside trufflehog on the same JS-intel/GitHub-leak corpus for one cycle and diff the verified hits; if it surfaces real secrets trufflehog's detectors miss, add it as a supplemental (not replacement) confirm step. Don't rip out trufflehog.
