## 2. HTTP request smuggling — desync frontier (class-request-smuggling)
Kettle's "HTTP/1.1 Must Die" work generalized: CL.0 (frontend honors Content-Length, backend ignores it), Browser-Powered Desync Attacks (BPDA) — a *fully spec-compliant* browser `fetch()` can poison the victim's own connection pool, no crafted raw socket needed. New **pause-based detection**: send headers promising a body, then pause before sending it — if the server responds before the body arrives, the backend already finished parsing on Content-Length alone (frontend is ignoring/truncating it) → CL.0 candidate. Source: [PortSwigger BPDA research](https://portswigger.net/research/browser-powered-desync-attacks), [Imperva chunk-extension desync](https://www.imperva.com/blog/smuggling-requests-with-chunked-extensions-a-new-http-desync-trick/).
⚠️ CVE-2025-32094 (Akamai/LastPass 0.CL) and CVE-2025-55315 (chunk-extension smuggling) appeared only in a secondary aggregator (instatunnel.my), not the PortSwigger primary — NVD-verify before citing in any report.
